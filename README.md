# CustodiaChain

## Requisitos

- Node.js 18.17 o superior (recomendado 20 o 22). Comprueba con `node --version`.
- npm (viene con Node.js).
- Un navegador actual (Chrome, Edge o Firefox).

## Instalación

```bash
cd frontend
npm install
```

## Cómo correrlo

```bash
npm run dev
```

Abre http://localhost:3000 en el navegador. En la página de inicio pulsa **Cargar datos de ejemplo** para ver el flujo completo.
